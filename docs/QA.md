# 탕비실 검증 상태
최종 갱신: 2026-11-06. 현재 구현은 [DEVELOPMENT](DEVELOPMENT.md), 실행법은 [README](../README.md)를 따른다. 기능 검사와 실제 사용성·청취 평가는 구분한다.

## 공개 배포 준비
Node 24 다단계 `Dockerfile`과 빌드 입력만 허용하는 `.dockerignore`를 추가했다. 기존 로컬 서버·DB는 유지했다. `HOST`/`PORT`/`PANTRY_DB` 지원은 기존 구현을 사용하며, 포트 자동 할당 시 시작 로그에 실제 포트를 표시하도록 고쳤다. 서비스 설정은 [README](../README.md)의 1개 인스턴스·`/data` 영속 볼륨·상태 확인 표를 따른다.

- **실행 구성 검사 통과:** `npm run check:runtime`이 임시 폴더에 `dist`, `server`, 공용 `.mjs`만 복사해 실행했다. 환경 파일·패키지·node_modules·기존 DB 없이 새 DB를 만들었고 `0.0.0.0` 및 동적 `PORT`로 접속했다.
- **프록시/연결 검사 통과:** 로컬 HTTP 프록시가 공개 Host·HTTPS Origin을 전달하는 조건에서 두 방문자가 입장·간식 나눔·시식했다. 다른 Origin은 403, SSE 첫 스냅샷 즉시 수신·버퍼링 방지 헤더·10초 heartbeat를 확인했다. MP4 부분 요청도 206으로 반환했다.
- **저장 복구 검사 통과:** 임시 프로세스를 종료·재시작하고 같은 토큰으로 재접속해 시식 출처·빈 접시·예산 50과 제공자의 한입 상태를 복구했다. 임시 서버·프록시·DB는 검사 후 정리했다.
- **빌드/타입 검사 통과.** 게임 소스와 자산 번들 해시는 이전 검증본과 같다. 이전 전체 55개 검사는 아래 기록을 유지하며 배포 파일 변경만을 이유로 다시 반복하지 않았다.

이 PC에는 Docker가 없어 실제 이미지 빌드/컨테이너 실행은 미검증이다. 위 검사는 로컬 Windows Node 실행 및 프록시 헤더 모사이며 실제 TLS, Railway 볼륨 권한, 플랫폼 SSE 재접속, 실제 휴대폰 둘의 접속을 증명하지 않는다. 외부 배포 담당은 Docker 빌드 → `/api/health` → HTTPS 두 방문자 → 서버 재배포 후 기록 보존을 확인한다. 계정 연결·서비스 생성·유료 설정·기존 Cloudflare 검증 명령은 이 작업에서 실행하지 않았다.

## 최신 빌드: 모래 반응·실녹음·동료 동작·꽃병
기존 DB를 초기화하지 않고 독립 방문자 A(1280×720)·B(터치 Chromium 390×844, 320×568)로 실행했다. 차 준비 → 힐링방 → 모래 → 내려놓기 → 복귀를 수행하고, 모래/꽃병의 교체·중단·재집기를 확인했다.

- **직접 입력:** 긴 획이 64점씩 두 번 저장되어 모두 200을 받았다. 앞선 선을 단순화하지 않고 이어 그린 결과와 청크 저장 결과가 같은 자동 검사도 통과했다. 물체 swipe/꽃병 방향키 전후 카메라 좌표·yaw/pitch는 같았고 방 swipe/방향키만 시선을 바꿨다. 이동 중 선택한 시선이 착석 후 유지되는 카메라 검사 5개도 유지했다.
- **크기:** 320×568/390×844 실제 방 캔버스 높이는 394/670px, 가로 넘침 없음. 모래 주 행동·다듬기·내려놓기는 44px 높이였다. 최종 캡처는 입력/저장과 화면 갱신이 끝난 뒤 촬영했다.
- **소리 계측:** 기본 무음·씹는 소리 끄기, 파도만 상태의 모래 소스 시작 0회, 파도와 행동 상태의 짧은 변주를 관측했다. 드래그 7회 시작의 rate는 약 0.970, release 시 남은 소스에 약 40ms fade/45ms stop이 예약됐다. Enter/Space도 각 0.3초 클립을 재생한다. 모래 입력 중단/비활성/공간 전환/연결 종료 정리와 동료 contact 종료를 확인했다. 원음 4개 편집의 PCM 끝 샘플 0·클리핑 0, 모래 peak -23dBFS/돌 -26dBFS를 확인했다. 이는 청취 평가가 아니다.
- **개인 꽃병:** 실제 선반 접근, 세 꽃 중 선택, 줄기/꽃잎 드래그와 탭·방향키·버튼, 내려놓기와 재집기. 위치·기울기·꽃 선택은 왕복/새로고침 후 유지되며 다른 방문자의 꽃병을 덮어쓸 수 없다. 모래→꽃병→놓기, 꽃병→모래→놓기 양방향에서 마지막 도구가 주 버튼으로 복구되고 새로고침에도 남는다. 독립 검토 채팅도 같은 결과를 확인했다.
- **동료:** 한 명 단독, 두 독립 브라우저, 여섯 인증 연결 상태를 구분했다. 6명 검사는 두 실제 화면과 추가 4개 SSE 방문자로 수행했으며 6명이 동시에 조작한 사용자 시험은 아니다. 여섯 자리가 각각 예약되고 현재 방 인원 6, 이미 점유된 자리 요청 409를 확인했다. 가까운 동료의 걷기/착석·짧은 모래 손동작·잔 들기를 촬영했다. 기본 손은 무릎으로 내리고, 잔을 입 아래로 가져가도록 팔 도달점을 고쳤다. 뒷사람 이름이 앞사람 이름처럼 겹치는 경우를 숨기고 가까운 이름을 우선한다.
- **공개 범위:** 모래 공개 값은 held/revision/changedAt/changedKind, 꽃병은 flower/held뿐이다. 선/돌/꽃 배치/개인 ID는 다른 방문자의 스냅샷에 없다. 입력 종료 뒤 contact=null이며 지연 패킷이 동작을 되살리지 못한다. 다른 방의 동료는 렌더링/소리 대상에서 빠진다.
- **기존 흐름:** 이동 중 멈추기→재출발, 두 방문자 동시 출입의 서로 다른 자리, 도구 자동 보관을 확인했다. B의 차 0.233666…와 모래 revision 2는 왕복 후 같았고, 이후 직접 마시는 행동에서만 차 양이 줄었다. 기존 시식 받기→먹기 후 empty/나눔 버튼 0개, 추가 offer 요청 409를 재확인했다. 독립 검수는 42% 부분 개봉과 꽃·차·모래의 복구도 확인했다.

증거: `test-results/polish-final-{320,390}.png`, `polish-final-vase-1280.png`, `polish-resting-two-1280.png`, `polish-peer-tea-final.png`, `polish-six-final-1280.png`. 중간 `polish-peer-tea.png`는 컵 위치 수정 전 비교용이다. 초기에 숨겨진 ‘꽃병 재집기’와 Enter 무음은 독립 검토에서 발견해 수정·재검사했다.

미리듣기는 `test-results/sound-A-waves.wav`(12초 파도만), `sound-B-waves-and-sand.wav`(동일 파도+모래/돌)다. 편집 클립으로 만든 비교 믹스이며 브라우저 출력 녹음은 아니다. 원음 링크·라이선스·편집 구간·gain/fade·해시는 `src/assets/audio/REST_CREDITS.{json,txt}`, 재현 스크립트는 `scripts/prepare-sand-audio.py`에 있다.

## 유지한 시점과 작은 화면
앉아서 마우스·터치·방향키로 자유롭게 둘러보고, 이동 중 직접 고른 방향은 도착해도 유지한다. 눈 위치만 착석 높이로 움직인다. 바다 보기/Home은 명시적으로 선택할 때만 적용된다. 기존 착석 시선 실제 증거는 `seated-look-{desktop,390,320}.png`다.

하단은 탐색 48px·행동 52px·아래 여백 8px를 기준으로 장면을 우선한다. 열린 선택 목록만 방 위에 놓이고 서로 닫히며, 주요 조작은 44px 이상을 목표로 한다. 기존 모바일 개선의 전후 증거는 `compact-{before,after}-{320,390}-{plant,stone,tea}.png`다. 실물폰 시험을 뜻하지 않는다.

## 유지되는 기능 검증
아래는 같은 날짜의 휴식 도구 구현 및 이전 통합 검사에서 확인한 결과다. 이전 실제 조작 결과이며, 최신 자동 회귀 검사와 구분한다.

- **두 방문자와 저장:** 독립 브라우저 C(1280×720), D(390×844/320×568)가 식물·말랑돌·차를 사용했다. 다른 사람의 설비 점유 중 목적지는 선택 불가였고 떠나면 해제됐다. 새로 연 동일 프로필에서 물건·양·먹던 파이·기록을 복구했다.
- **식물/말랑돌:** 집기·분무·내려놓기·잎 쓸기·이탈, 말랑돌 클릭/터치/Enter·국소 변형·복원·재집기·반납. 빠른 재입력은 추가 입자/소리나 오류창을 쌓지 않았다.
- **차:** 별도 잔·티백·붓기/멈추기/재개·티백 받침·가져오기·한 모금·재집기를 수행했다. 붓기 도중 연결 종료 후 약 150ms 검사에서 붓기 종료, 양 0.683, 개인 트레이 반환을 확인했다. 기존 5초 연결 유예 후 다른 사람에게 목적지가 풀렸다.
- **레몬파이:** 39.3% 개봉→새로고침→이어 열기→먹기 전 나누기→한입. 다른 방문자는 찻잔을 내려놓고 시식을 받아 먹었다. 공유 출처 발견·예산 50과 기존 차·말랑돌을 보존했다.
- **사탕/커피/병:** 사탕 클릭/탭 한 번 개봉, 커피 추출·가져오기·이동 중 취소, 냉장고 열기·병 꺼내기·자동 닫기와 남은 모금 복구를 실행했다. 원격/미도착 조작, 이중 점유와 중복 요청을 서버에서도 검사한다.
- **바다/복구:** 24초 경계를 지나 실제 반복 재생, WebM 실패 시 MP4, 둘 다 실패 시 정지 원경과 입장 유지. 동작 감소 초기 정지·사용자 재생 선택, 탭 비활성/모달 중단. 이전 빌드의 지연 자산 실패 시 한 번 새로고침해 저장된 간식으로 복귀했다.
- **소리 계측:** 기본 무음에서 WAV 요청 0. 분무 0.48초 한 소스와 빠른 재입력 억제, 차 소스 시작/중지 관측. 두 방문자 검사에서 최대 동시 2개를 관측했으며 구현 상한 6개/동료 2개의 실제 6인 청취 평가를 뜻하지 않는다. PCM 클리핑/끝 샘플/해시는 자산 기록에 있다.

대표 이전 캡처: `rest-final-plant-1280.png`, `rest-final-stone-1280.png`, `rest-final-tea-close-1280.png`. 초기 수정 전 캡처나 구버전 전체 보기/3인칭 캡처는 현재 품질의 증거로 인용하지 않는다.


## 자동 검사와 재실행
최종 전체 **55개 통과**, TypeScript·Vite 빌드 통과. 서버/소유권/중복 요청·나눔/예약/모든 가구 경로/미디어 범위/실제 DB 재개방, 카메라, 긴 모래 획 동일성, 접촉 신호의 순서/기한, 꽃병의 사유화/제약/보관, 컵 손 위치, 오디오 끝 샘플을 포함한다. 공용 Three.js 청크 500KB 이상 빌드 안내는 남는다.

Node.js 24 이상에서:
```sh
npm run typecheck
npm test
npm run build
```
별도 방문자/방을 사용하고 실제 DB를 초기화하지 않는다. 토큰은 로그·캡처·문서에 남기지 않는다. 완료한 검사를 새 변경/실패 없이 반복하지 않는다.

## 외부 관찰과 미검증 범위
아직 실제 첫 사용자 5~8명, 실물 iPhone/Android·Safari, 저사양 발열/프레임/배터리, 헤드폰 음색·반복 피로·6인 청취를 시험하지 않았다. 인터넷 공개 배포/부하/계정 복구도 별도다.

관찰자는 조작법을 먼저 설명하지 않고 “잠깐 쉬었다가, 원할 때 돌아와 주세요”만 제시한다. 처음 고른 대상, 차 준비/이동에서 망설인 곳, 선 하나를 그리는 데 걸린 단계, 내려놓기·다시 집기·복귀를 스스로 찾았는지 기록한다. 막힌 시점에만 이유를 묻고 정답/완주를 요구하지 않는다. 끝에 불편했던 순간과 다시 하고 싶은 행동을 자유롭게 묻는다. 소리는 무음/A/B를 편안한 음량으로 비교하고 거슬림·반복 피로를 따로 받는다. 연구 근거와 측정 가능한 기능을 실제 편안함의 증명으로 대체하지 않는다.
