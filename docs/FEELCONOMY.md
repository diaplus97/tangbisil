# 탕비실의 필코노미 원칙과 첫 휴식 도구

## 제품 원칙

그날의 기분에 맞는 작은 행동을 스스로 골라 하고, 편해진 순간 멈출 수 있는 탕비실. 아무것도 하지 않아도 된다. 기능 수나 체류 시간 대신 편안함, 배우기 쉬움, 작은 감각 반응과 중단의 수월함을 평가한다. 기분 설문·감정 자동 추정·치유 점수·출석·보상·관리 숙제를 넣지 않는다.

현재 메인 방에는 식물·말랑돌·차, 별도 힐링방에는 기대앉기·개인 모래 트레이·작은 꽃병가 구현되어 있다. 넓은 1인칭과 앉은 상태의 자유 시선을 유지하며, 새로운 대상보다 기존 조작의 불편을 먼저 고친다. 구현 상세와 후속 범위는 [개발 기준](DEVELOPMENT.md), 실제 검증은 [QA](QA.md)를 따른다.

필코노미는 기분과 감정적 만족을 중시하는 소비 관점으로 사용하며 치료 효과를 뜻하지 않는다. 전달받은 출판사 소개는 [미래의창](https://www.miraebook.co.kr/bbs/board.php?bo_table=m02_01&wr_id=557), 공저자 설명은 [권정윤 칼럼 PDF](https://pdf.dema.mil.kr/pdf/pdfData/2025/20251127/B202511271601.pdf)다. 출판사 본문 접근은 불안정하므로 검색 색인의 확인과 원문 확인을 혼동하지 않는다. 기획의 권위보다 실제 사용 중 불편을 우선한다.

## 행동을 고르는 기준

| 현재 대상 | 경험의 목적 | 피할 요소 |
| --- | --- | --- |
| 창가 식물 | 한 번 분무하면 잎과 물방울이 작게 반응한다. 놓고 떠나기 쉽다. | 시듦, 관리 수치, 알림, 실패 |
| 말랑돌 | 누른 자리가 변형되고 천천히 돌아온다. 클릭·탭·키 한 번으로 반응한다. | 횟수, 콤보, 강제 타이머, 정밀 드래그 요구 |
| 힐링방 모래 | 선 하나 긋기, 돌 놓기, 표면 고르기 중 원하는 행동만 한다. 남긴 모양은 개인 상태로 보관한다. | 정답/패턴 완성, 점수, 작업 훼손, 정밀 드래그 강요 |
| 꽃 한 송이 | 내 자리에서 꽃의 위치와 기울기를 고르고 놓는다. 마지막 도구를 바로 다시 집는다. | 시듦, 관리 과제, 선물/답례, 수집 압박 |
| 보리차 | 내 잔을 준비하고 원할 때 붓기를 멈추거나 가져간다. | 강제 대기, 완성 전 이탈로 물건 소실, 기존 커피 잔 덮어쓰기 |

20~40초의 차 준비는 초기 설계 목표이지 과학적으로 검증된 적정 시간이나 강제 대기가 아니다. 손이 찼을 때 내려놓고 바꾸는 문구를 먼저 보여주며, 각 상태에서 대표 행동과 그만하기를 찾기 쉬워야 한다. 사물·좌석 선택은 ‘둘러보기’로 묶어 하단에 버튼을 계속 늘리지 않는다.

소리는 기본 무음이고 씹는 소리는 따로 선택한다. 실제 녹음을 우선하며 제작자·라이선스·편집 기록을 자산과 함께 보관한다. 가까운 내 소리와 먼 동료 소리를 구분하고 동시 재생을 제한한다. 파형/오디오 그래프 검사는 듣기 좋은지를 대신 증명하지 않는다.

## 평가와 보류

기능 검증과 처음 방문한 사람의 편안함 검증을 구분한다. 브라우저의 두 방문자·세 화면에서 발견→접근→사용→중단→재집기→자리 복귀를 검사하고, 가림·잘림·카메라 오조작·점유·소유권·새로고침을 확인한다. 결과와 미검증 기기는 QA에만 기록해 중복 완료 목록을 만들지 않는다.

실제 첫 사용자 5~8명의 짧은 관찰은 아직 진행하지 않았다. 설명 없이 발견한 대상, 귀찮았던 단계, 좋았던 반응, 중단 방법을 찾았는지 관찰한다. 감정 점수를 강제로 입력하게 하거나 기능 테스트로 사용성 검증을 대체하지 않는다.

승인된 힐링방과 개인 모래 트레이는 현재 구현 범위다. 차와 먹던 간식을 가져가 쉬고, 모래를 만지거나 아무것도 하지 않아도 된다. 나가면 모래와 꽃병을 보관하며 유지 의무나 완성 요구가 없다. 개인 꽃병의 꽃 한 송이와 모래 실녹음까지 연결했다. 추가 피젯·흡연실 내부는 별도 범위 결정이 필요한 후속 항목이다. 답례 압박, 인기 순위, 시듦을 만들지 않는다.
